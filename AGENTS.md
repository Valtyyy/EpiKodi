# Open Mosaik (EpiKodi)

Linux living-room media center: a TV interface (Tauri + React) controlled from a phone browser (web remote). Epitech project. Project documentation (`ARCHITECTURE.md`, ADRs, spikes, README) is written in **French**; code, identifiers, code comments and commit messages are in **English**.

Design source of truth: [ARCHITECTURE.md](ARCHITECTURE.md) (§1 constraints C1 to C7, §3 DI, §5 playback, §7 extensions, §8 API, §9 config). Settled decisions: `docs/adr/`. Experiment results: `docs/spikes/`. Read the relevant section before touching a component; do not contradict an accepted ADR without writing a new one (skill `new-adr`).

## Layout

```text
crates/core         domain, services, ports. NO native dependency (no Tauri, GTK, libmpv)
crates/infra        SQLite, SMB, TMDB, MusicBrainz, secrets, images
crates/player-mpv   PlayerEngine via libmpv
crates/remote-api   axum router + stream gateway
crates/ext-host     binary: QuickJS + sandbox (one process per extension)
crates/ext-protocol JSON-RPC messages, manifest, permissions (types only)
src-tauri/          composition root, Tauri commands, GTK surface
ui/tv               React, 10-foot interface (inside WebKitGTK)
ui/remote           React, phone remote (embedded in the binary via rust-embed)
ui/shared           generated types (ts-rs), API client, common components
spikes/             throwaway experiments, OUTSIDE the Cargo workspace
```

Dependency direction: `src-tauri → {infra, player-mpv, remote-api} → core`. The root npm package is `open-mosaik`; crates are named `om-*` (e.g. `om-core`).

## Commands

Prerequisites: Node 22, pnpm 10, stable Rust (edition 2024). System dependencies: see README.

```bash
pnpm install
pnpm tauri dev          # full app in development
pnpm dev                # ui/tv only (Vite)
pnpm build              # frontends (pnpm -r build); required BEFORE compiling Rust (rust-embed)
pnpm test               # cargo test --workspace --all-features + vitest, offline
pnpm lint               # ESLint
pnpm typecheck          # tsc
pnpm fmt                # cargo fmt + prettier --write
pnpm gen:types          # regenerate ui/shared/src/generated (ts-rs)
cargo clippy --workspace --all-targets --all-features -- -D warnings
```

Single Rust test: `cargo test -p om-core <name>`.

## Hard rules

1. **`core` stays pure.** No import of Tauri, GTK, libmpv, network or direct filesystem access. All I/O goes through an injected port (`trait`) (C5).
2. **Constructor injection**: a service receives its dependencies in `new()`, never `AppHandle` or `State`. `State<'_, T>` only appears at the boundaries (Tauri commands, axum handlers). Only `src-tauri/src/bootstrap.rs` knows both services and concrete implementations (ADR-0003).
3. **No `<video>` or `<audio>`**: playback goes through libmpv (C1).
4. **No `panic = "abort"`** in release: a panic in a task must not kill the app.
5. **No network call on a UI playback path**; an unreachable source is never interpreted as "files deleted" (C6).
6. **Typed settings applied hot**; secrets are write-only through `SecretStore`, never in logs or git (C7, §9).
7. **Rust ↔ TS shared types are generated by ts-rs**: never hand-edit `ui/shared/src/generated`. After changing an exported type, run `pnpm gen:types` and commit the result (CI fails otherwise via `scripts/check-types.sh`).
8. **Tests run offline**, and without GTK or libmpv for `core` and `remote-api`.

## Git and CI

- Branches `feat/epic-NN`; PRs target `main`; `main` is protected (`docs/branch-protection.md`).
- **Conventional Commits** enforced by commitlint (`feat:`, `fix:`, `ci:`, `chore:`, `docs:`…), `commit-msg` hook via lefthook.
- Pre-commit hook: prettier, eslint, `cargo fmt --check` on staged files.
- Required CI jobs (do not rename, see branch-protection.md): `Build frontend`, `Lint`, `Clippy`, `Tests + types`, `Commitlint`.
- Never commit or push without an explicit request.

## Style

- Rust: `rustfmt` (edition 2024), `clippy -D warnings`. Async `dyn` ports use `async-trait`.
- TS/React: Prettier (`printWidth` 100, `trailingComma: all`), ESLint flat config, React 19, strict TypeScript.
- No comment that restates the code; comment the "why" (constraint, pitfall, relevant ADR).
